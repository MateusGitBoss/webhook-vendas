💸 webhook-vendas

Recebe os avisos automáticos de venda da Hotmart e da Kiwify, confere se são verdadeiros, grava cada venda uma vez só e avisa a equipe no Discord.

Demonstração. Tudo roda no seu navegador, com dados fictícios: não há servidor, banco nem Discord de verdade. As regras (tradução de cada plataforma, ordem dos status, assinatura HMAC, máscara de dados pessoais) são cópias do código Python, conferidas contra ele ao abrir a página (veja o fim).

Regra dos status

A internet não garante a ordem dos avisos: o reembolso pode chegar antes da aprovação. Por isso cada status tem um peso e só se troca para um peso maior. A única exceção é cartão recusado que depois é aprovado.

Linha: status gravado. Coluna: status que chegou. ✔ = muda, · = ignora.
